Название проекта: MagazAvtoZap (Магазин Автозапчастей)
Разработчик: Шайко Леонид Викторович 

Описание:
Информационная система для автоматизации работы магазина автозапчастей.
Приложение позволяет вести учет товаров, оформлять заказы клиентов и управлять их статусами.

Функционал:
1. Клиентская часть:
   - Просмотр каталога товаров.
   - Добавление товаров в корзину.
   - Оформление заказа (с валидацией данных).
2. Административная часть:
   - CRUD операции с товарами (Добавление, Редактирование, Удаление).
   - Просмотр истории заказов.
   - Управление статусами заказов (Новый -> Отправлен -> Завершен/Отменен).
   - Автоматический учет остатков на складе при смене статусов.
   - Просмотр истории продаж.

Технические требования:
- Платформа: .NET (WPF)
- База данных: MS SQL Server (LocalDB или SQL Express)
- Архитектура: Трехслойная (View - BusinessLogic - DataAccess)

Инструкция по запуску:
1. Убедитесь, что установлен MS SQL Server.
2. Разверните базу данных из скрипта (или убедитесь, что она создана).
3. В файле App.config проверьте строку подключения connectionStrings.
4. Запустите файл MagazAvtoZap.exe.
